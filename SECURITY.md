# Security and responsible use

PhysTTA is research software and must not be used for diagnosis, patient triage, or clinical decision-making.

Please report a security or privacy issue privately through GitHub's security-advisory interface. Do not open a public issue containing credentials, protected health information, private dataset paths, or exploitable details.

Before sharing an experiment artifact, check that it contains no patient identifiers, access tokens, signed URLs, private storage locations, or model weights with restricted redistribution terms.
